# OSINT Utility Telegram Bot

Небольшой Telegram-бот для проверки публичной технической информации об инфраструктуре и приватной обработки изображений. Бот не ищет людей по номеру автомобиля, лицу, фото или никнейму, не строит персональные досье и не сохраняет запросы в базе данных.

## Возможности

- `/domain example.org` — публичные DNS-записи A, AAAA, MX, NS и TXT.
- `/ip 8.8.8.8` — определение типа IP-адреса и его опубликованной обратной DNS-записи (PTR).
- `/url https://example.org/path` — разбор URL и DNS домена; бот не загружает страницу.
- Отправка изображения — пересохранение JPEG/PNG/WebP без встроенных метаданных (например, EXIF).

Бот не определяет геолокацию IP, владельцев доменов/адресов или личность людей. DNS-сводка может содержать общедоступные технические записи.

## Запуск

Требуется Python 3.10+ и токен Telegram-бота, созданный через `@BotFather`.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="ваш_токен"  # PowerShell: $env:TELEGRAM_BOT_TOKEN="ваш_токен"
python bot.py
```

Не публикуйте токен в репозитории и не отправляйте его в чат. Для постоянной работы запустите процесс на своём сервере/хостинге и задайте `TELEGRAM_BOT_TOKEN` в настройках секретов окружения.
